المقدمة

من اهم اللغات المستخدمه فى تصميم صفحات الويب حيث تساعد على تنسيق شكل الصفحة واضافة الالوان والخطوط والخلفيات مما يجعل المواقع اكثر جمالا وتنظيما css تعد لغة

تعريف اللغه

CSS هي اختصار لـ Cascading Style Sheets، وهي لغة تُستخدم لتصميم وتنسيق صفحات الويب، وتحديد الألوان والخطوط والخلفيات والمسافات، مما يجعل المواقع أكثر جمالًا وتنظيمًا.

اهمية اللغه

لفة تساعد في تحسين شكل صفحات الويب وتنظيم المحتوى وتغيير الألوان والخطوط والخلفيات، كما تساعد في جعل المواقع متوافقة مع الهواتف وأجهزة الكمبيوتر css

مميزات لغة css

  • تساعد في تحسين شكل صفحات الويب
  • تساعد في تنظيم المحتوى
  • تساعد في تغيير الألوان والخطوط والخلفيات
  • تساعد في جعل المواقع متوافقة مع الهواتف وأجهزة الكمبيوتر
العنصر الاستخدام
الالوان تغير الوان النصوص والخلفيات
الخطوط تغير نوع وحجم الخط
الخلفيات تغير خلفيات الصفحات
التنسيق تنسيق شكل وترتيب عناصر الصفحات
